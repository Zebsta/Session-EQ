# AIMP / VLC / Session EQ: цифровое сравнение

Отдельная тестовая ветка. `Session-EQ-0.6.1-aimp-test.apk` разрешает подключение
к AIMP; `main` и обычный релиз 0.6.1 продолжают его исключать. Версия теста
видна в «О приложении», имя в launcher — `Session EQ (AIMP test)`.
DSP, Rock, другие пресеты, темы и служба ожидания не изменены.

Тестовая сборка заменяет установленный Session EQ, сохраняя настройки. Package ID,
подпись и versionCode 14 совпадают с 0.6.1; исходный APK 0.6.1 можно установить
обратно без очистки данных. Для теста разрешён AIMP во всех точках подключения.
После завершения убери его отметку «Авто» и верни обычную сборку.

## Подготовлено заранее

- APK теста и исходный APK 0.6.1 для возврата.
- Официальный scrcpy **5.0.1** для Windows x64. [Релиз и SHA-256](https://github.com/Genymobile/scrcpy/releases/tag/v5.0.1).
- `setup.ps1` проверяет SHA-256 архива и распаковывает локально; телефон не трогает.
- `record.ps1` запускает запись только при явном вызове, каждый раз проверяя
  доступность и авторизацию телефона. Файлы не перезаписывает.
- `compare.py` и тесты анализа. Результат: JSON с уровнями/выравниванием и PNG
  со спектрами и их отношением. Записи и отчёты не коммитятся.

На Windows набор находится в `Загрузки/Session-EQ-audio-test`.
Если scrcpy ещё не распакован:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
```

## Условия всех прогонов

Один и тот же MP3 на телефоне, запуск с начала, одинаковая громкость и устройство
вывода. Проигрыватели запускаются по очереди. Скорость 1x. Не менять ReplayGain,
нормализацию, системные эффекты, AUTO, предусиление или лимитер между дублями
одного условия; их значения записать в `-Notes`. Для базового сравнения встроенный
EQ VLC выключен, нормализация и ReplayGain в обоих плеерах выключены.
Отключить посторонние звуки/уведомления на время записи. Микрофон не используется.

## Сначала проверка точки захвата

Начать с коротких дублей Flat и с сильным ослаблением полосы 1 kHz в Session EQ.
Если изменение не попало в запись, точка захвата не подходит: нельзя делать
вывод об эквалайзере по одинаковым WAV. Также проверить отсутствие тишины,
срыва записи и влияние системной громкости. Это проверяется на телефоне,
успешные синтетические тесты анализатора этого не доказывают.

Основной режим — `playback --audio-dup`: звук остаётся на телефоне.
Некоторые приложения запрещают такой захват. В этом случае можно проверить
`output`, но он меняет маршрутизацию и отключает местное воспроизведение.
Этот вариант тоже требует проверки точки захвата. Не смешивать источники в
одной паре сравнения; анализатор проверяет JSON-метаданные и откажется их смешивать.
Ни один способ внутреннего захвата не гарантирует запись всей обработки
физического выхода на наушники.

[Источники звука scrcpy](https://github.com/Genymobile/scrcpy/blob/v5.0.1/doc/audio.md)
и [запись WAV](https://github.com/Genymobile/scrcpy/blob/v5.0.1/doc/recording.md).

## План на 18 ноября 2026

| Имя записи | Плеер | Его EQ | Session EQ |
| --- | --- | --- | --- |
| calibration-flat | VLC | OFF | Flat |
| calibration-notch | VLC | OFF | Flat, полоса 1 kHz −15 dB |
| vlc-off | VLC | OFF | OFF |
| vlc-rock | VLC | OFF | Rock |
| aimp-off | AIMP | OFF | OFF |
| aimp-rock | AIMP | Rock | OFF |
| aimp-sessioneq-rock | AIMP | OFF | Rock |

Не включать одновременно встроенный EQ AIMP и Session EQ при сравнении.
В тестовой сборке AIMP выбирается как обычный плеер. Если Android показывает
несколько внешних эквалайзеров, выбирать `Session EQ (AIMP test)`.

Настроить нужное условие, поставить трек на начало/паузу, вызвать запись,
затем сразу запустить воспроизведение с начала:

```powershell
.\record.ps1 -Name vlc-off -Seconds 45 -Notes 'Same MP3; VLC EQ off; Session EQ off; volume/device fixed'
```

Имена для следующих дублей уникальные (`vlc-off-2` и т. п.). Для проверки
альтернативного источника явно добавить `-Source output`. По умолчанию
используется `playback`. Запись завершится сама; WAV, JSON и лог сохранятся
в `recordings`. Скрипт не запускает музыку и не переключает настройки плееров.

## Анализ

Подготовлен Python-venv на рабочем Linux-компьютере. Для воспроизведения среды:

```sh
python3 -m venv .venv
.venv/bin/pip install -r tools/audio-lab/requirements.txt
.venv/bin/python -m unittest discover -s tools/audio-lab -p test_compare.py -v
.venv/bin/python tools/audio-lab/compare.py recordings/aimp-rock.wav recordings/aimp-sessioneq-rock.wav --out reports/aimp-comparison
```

Сначала сравнить VLC OFF/ON, затем AIMP OFF/ON, затем AIMP со встроенным Rock
против AIMP с Session EQ Rock. Отдельно сравнить базовые записи VLC OFF и AIMP OFF.

Анализатор выравнивает целочисленную задержку, при необходимости приводит
частоты дискретизации, отдельно показывает исходную разницу уровня и сравнение
с выровненным усилением. Тишина и ненадёжное выравнивание отвергаются.

Ограничения: не компенсируются дрейф часов и дробная задержка; они влияют на
остаточную разность. RMS не равен LUFS, sample peak не равен true peak.
Отношение спектров музыки не является точной АЧХ фильтра: в него входят
декодер, ресемплинг, лимитер, уровни и маршрут захвата. Нулевой остаток не требуется
для субъективно похожего звучания. До проверки на устройстве данные о реальном
совпадении звучания отсутствуют.
